# 自然な日本語にするための推敲ガイド

AIが書いた日本語は、個々の文は正しくても「全体の癖」で見抜かれる。読者は有料記事にお金を払っているので、AIっぽさに気づいた瞬間に「本当に体験した人が書いたのか」を疑い始める。推敲ではこの癖を消すことを最優先にする。

## 1. 避けたい定型表現と言い換え

| AIっぽい表現 | 言い換えの方向 |
|---|---|
| 「〜について解説します」「〜をご紹介します」 | 何が分かるかを具体的に書く／いきなり本題に入る |
| 「いかがでしたか？」 | 削除。自分の感想や次の一歩で締める |
| 「〜と言えるでしょう」「〜ではないでしょうか」の連発 | 体験なら言い切る。推測なら根拠を添えて1回だけ |
| 「重要です」「大切です」「ポイントです」の連発 | なぜ大事なのかを具体例で示し、ラベルは削る |
| 「〜することができます」 | 「〜できます」 |
| 「さまざまな」「多くの」「魅力的な」「洗練された」 | 具体的な数・名前・場面に置き換える |
| 「まず」「次に」「最後に」で全段落を始める | 時系列なら日付や回数（「3回目の来店では」）で始める |
| 「結論から言うと」を毎回使う | 1記事1回まで |
| 「〜という方も多いのではないでしょうか」 | 「私も最初はそうでした」など自分の話に寄せる |
| 「本記事では」「当記事では」 | 「この記事では」、または省く |
| 「〜の魅力に迫ります」「〜の世界へ」 | 削除 |
| 「ぜひ参考にしてみてください」 | 削除するか、具体的な行動の提案に変える |

## 2. 構造の癖

- **三点列挙の多用**：何でも3つにまとめない。2つや4つでもよい
- **箇条書きの多用**：体験記は文章で書く。箇条書きは手順・持ち物・金額の内訳など、本当にリストの情報だけに
- **見出しの「〜とは？」連発**：見出しは内容が分かる短い文に
- **段落の長さが均一**：短い段落（1文）と長い段落を混ぜる
- **毎段落の最後にまとめ文**：「このように〜」「つまり〜」で締めない
- **記号の多用**：「：」「——」「！」「【】」を減らす。特にダッシュ（——）は日本語の文章では不自然になりやすい

## 3. 文末のバリエーション

「です」「ます」が5回以上連続したら変える。使える文末の例:
- 「〜でした」「〜ました」（過去形で場面を描く）
- 「〜んです」「〜んですよね」（気持ちを込める。多用はしない）
- 「〜かもしれません」（本当に不確かなときだけ）
- 体言止め（1段落に1回まで）
- 会話文の引用で終える

## 4. 具体性を足す

抽象的な文を見つけたら、次のどれかで置き換える。
- **数字**：時間、金額、回数、人数
- **場面**：どこに座ったか、何を見たか、何を聞かれたか
- **会話**：実際の一言（体験メモにあるものだけ。創作しない）
- **感情の変化**：「正直、帰り道は少し落ち込みました」

悪い例：「店内は洗練された雰囲気で、スタッフの方の対応もとても素晴らしかったです。」
良い例：「平日の14時でしたが、店内には先客が4組いました。15分ほど待って案内された担当の方は、最初に『今日はどんなものをお探しですか』とだけ聞いてくれました。」

## 5. 書き手らしさを残す

- 書き手が使った言葉（体験メモの言い回し）はできるだけそのまま使う
- 迷い、失敗、見栄を張ったことなど、少し恥ずかしい話が信頼を生む
- 読者への呼びかけは控えめに。「〜ですよね！」の連発は避ける

## 6. 最終確認の読み方

書き手本人になったつもりで頭から読み、「この人はこう言わないな」と感じた箇所を直す。音読して詰まる箇所は、文が長すぎるか読点の位置が悪い。

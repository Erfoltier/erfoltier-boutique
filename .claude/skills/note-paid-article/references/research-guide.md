# 調査・事実確認ガイド

ラグジュアリーブランドの販売事情は変化が速く、ネット上には古い情報や噂が大量にある。記事に書く「事実」は必ずその場で調べ直す。このファイルに具体的な価格や制度を書いていないのは、すぐ古くなるため。

## 情報源の優先順位

1. **ブランド公式**（公式サイト、公式オンラインストア、公式発表・プレスリリース）
   - 定価、取扱モデル、店舗の所在地・営業時間、予約制度の有無
2. **信頼できる報道**（新聞・経済誌・時計／ファッション専門メディア）
   - 価格改定の時期と改定率、販売方針の変更、購入制限の導入
3. **二次流通の実データ**（大手買取店・中古販売店の掲載価格、オークション落札価格）
   - 相場は「◯年◯月◯日時点、◯◯の掲載価格」と出典と日付を必ず添える
4. **個人の体験談**（ブログ、SNS、note、掲示板）
   - 事実の根拠にはしない。「こういう声もある」という傾向の参考に留め、引用する場合は伝聞であることを明示する

## よく確認が必要になる項目

### 共通
- 現在の定価（公式で確認できないモデルは「店頭価格」と区別する）
- 直近の価格改定の時期と内容
- 来店予約制度・抽選制度の有無と方式
- 購入制限（同一モデルの購入制限期間、本人確認、身分証の提示など）

### ロレックス
- 対象モデルごとの購入制限の内容（どのモデルが対象か、制限期間）
- 正規店での購入時の手続き（身分証、氏名記入など）
- 生産終了・新作発表（毎年の新作発表時期の前後で状況が変わる）

### エルメス
- バッグ（バーキン・ケリー等）の販売方法に関する公式の説明の有無
- 「実績」「購入履歴」に関する話は公式の制度ではないため、体験・伝聞として扱う
- 店舗の予約制度（来店予約、オンライン予約の有無）

## 書き方のルール

| 根拠の種類 | 書き方の例 |
|---|---|
| 公式情報 | 「公式サイトによると、2026年10月時点の定価は〇〇円です」 |
| 報道 | 「〇〇（媒体名）の報道によれば〜」 |
| 自分の体験 | 「私が〇〇店で言われたのは〜でした」 |
| 担当者の発言 | 「担当の方は『〜』とおっしゃっていました（店舗や時期で違う可能性があります）」 |
| 噂・通説 | 「〜とよく言われますが、私の経験では〜でした」 |
| 確認できなかった | 書かない、または「公式な情報は見つかりませんでした」と明記 |

## 調査メモの形式

記事とは別に、次の形で書き手に渡す。

```
## 調査メモ（確認日：2026-10-04）
- 事実：〇〇の定価は〇〇円
  出典：https://...（公式サイト）
- 事実：〇年〇月に価格改定
  出典：https://...（〇〇新聞）
- 未確認：〇〇という噂 → 公式情報なし。記事では体験ベースで記述
```

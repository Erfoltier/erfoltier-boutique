# 公開前チェックリスト

## 体験・事実
- [ ] 体験として書いた内容は、すべて書き手のメモや回答に基づいているか（創作した会話・場面がないか）
- [ ] 【要記入】が残っていないか。残っている場合は書き手に一覧で伝えたか
- [ ] 価格・制度・相場に「◯年◯月時点」と根拠が添えてあるか
- [ ] 噂や伝聞を事実のように書いていないか
- [ ] 調査メモ（出典URL・確認日）を作成したか

## 配慮・リスク
- [ ] 店舗スタッフの実名や、個人が特定できる特徴を書いていないか（店舗名は地域レベルにぼかすのが無難）
- [ ] 他の客について、特定できる書き方や否定的な書き方をしていないか
- [ ] 転売・購入代行を勧める内容になっていないか（ブランドの規約に反し、読者が購入制限を受ける原因にもなる）
- [ ] 「必ず買える」「この方法で確実」など、効果を保証する表現がないか
- [ ] ブランドの公式情報・公認であるかのように見える書き方をしていないか
- [ ] ブランドのロゴ画像や公式サイトの画像を無断で使っていないか（自分で撮影した写真を使う）
- [ ] アフィリエイトリンクや提供品がある場合、冒頭に「PR」「広告」などの表記があるか
- [ ] 書き手自身の個人情報（勤務先、住所が推測できる情報、総資産など）を書きすぎていないか

## 読みやすさ
- [ ] 冒頭3行で、誰向けで何が分かる記事かが伝わるか
- [ ] 有料ラインの直前に、有料部分で読める内容が具体的に書いてあるか
- [ ] 無料部分だけ読んでも1つは学びがあるか
- [ ] `scripts/check_ai_phrases.py` で検出された表現を見直したか
- [ ] 見出しは `##` と `###` だけになっているか（note の見出しは大・小の2段階）
